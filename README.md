# Etch-a-sketch
This repository contains a digital web based replica of the classical mechanical drawing toy Etch-a-sketch.

This website is made as a part of the odin project. I used basic DOM manipulation to achieve this website.

### Version 1.0.0
This is the first version of the website. The part where each time a grid is visited the color darkens is not added.

Tech Stack:
- HTML
- CSS
- Javascript
